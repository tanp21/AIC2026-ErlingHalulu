**Manual override in `temporal_config.json`: K=2000, min_gap_seconds=1.5.** This benchmark's 10s
tolerance ties every (K, scoring_method) row across all min_gap_seconds values on MRR/recall, so it
has no signal to pick either parameter correctly:
- `min_gap_seconds=1.0` regresses the exact-shot fix for `query-p2-21-trake` (L30_V031) — verified
  directly against production data that only 1.5s+ lands the DP on the correct shot for every event;
  1.0s collapses events 3 and 4 into the same shot again.
- `candidate_k=1000` silently drops a legitimate, non-overlapping secondary sequence for the same
  video (its anchor candidate ranks #1023 for its event, just outside the top-1000), reducing how
  many disjoint answer candidates get surfaced to reviewers without any change in top-1 accuracy.
  K=2000 restores it.

`scoring_method=shifted_harmonic` is kept from this run (tied-best, no downside found).
